## 当前本地修改

桌面端连接设置默认显示紧凑设备卡片，SSH 使用独立页签。每台已配对电脑提供刷新对话、断线重连与折叠的技术详情。左侧主栏显示远程工作区及其对话，行末带有地球仪标记；标识按设备隔离，避免不同电脑上的同名 Session 标识冲突。分组、平铺和搜索视图共用滚动区域、查询和归档筛选。挂载中的界面共用一个轮询器，最多同时读取两台电脑，连接失败时保留上次成功的目录。新增的授权接口 `workspace/list` 提供保存的名称和已登记的空文件夹；旧版设备按已授权对话的目录分组，并明确显示提示。完整工作区信息需要两台电脑均安装新版。远程对话仍在证书固定的隔离窗口打开；本次未嵌入远程文件浏览器。

手机聊天复用桌面图标和主题颜色，左侧记录抽屉底部提供设置，顶部显示对话标题，圆角输入框下方提供模型和思考强度。长表格、代码、公式及引用预览各自滚动，键盘挤压后的短视窗保留发送及批注操作。原生设置改用紧凑描边按钮和设备卡片。本地及远程页面的原生长按菜单提供添加批注，安卓关闭菜单后仍保留引用。旧 Tailscale 配对改走应用内节点，无需另一个安卓 Tailscale 的开关；前台启动恢复节点、刷新远程对话并重试离线连接，主动退出应用内节点后暂停恢复。本次新增恢复上次页面与上次手机会话、远程页原生连接状态条、断线自动重连并重载同步、离线保留远程对话列表。桌面与安卓手机聊天的批注均改为带 1-based 编号的独立块；桌面提示词明确各条独立、评论只作用于自己的引文、空评论是整体请求目标、禁止合并/转派，发送后的注释详情显示与草稿弹窗一致的编号。本轮另修复排队消息预览/编辑把 `<dsh-response-annotations>` 原文显示出来的问题：队列只显示正文，编辑保存时保留注解。模型与思考强度选择、流式 Messages、按账号压缩保存草稿、Markdown/TeX 批注、可选副本同步及固定证书/可撤销远程授权均保留。构建和交付核验结果已写入 state.json。

桌面设备行按钮会先探测并直接向所选电脑请求批准，不再只是展开配对码表单。关闭面板会取消待处理操作，包括尚未结束的探测。接收端恢复最小化窗口，并显示适用于各类设备的授权说明。DSH 设备批准与 Tailscale 登录分别处理，批准结果由系统加密保存；不能因为处于同一 Tailnet 就删除用户批准环节。手动配对码保留为备用。

## 实现边界

安卓应用权限不能直接用 Go netlink 枚举网卡。[TailnetClient.java](../../../apps/android/app/src/main/java/io/jadegate/dsh/companion/TailnetClient.java) 把 SDK 可见网卡提供给[原生组件](../../../apps/android/tailnet/main.go)。Android+cgo 不注册 androidbin fallback，单独 import 无效。保留 cgo/bionic 域名解析，不要加 netgo 构建标签。

[电脑引导连接](../../../apps/desktop/src/tailnet-pairing.ts) 仅绑定本机 Tailscale IPv4 的 42873 端口，先由本机 daemon 核验真实来源，再让用户批准。不能信任转发头或对方自报名称。每台手机授权独立、可撤销，Host Cookie 留电脑；已启用的 LAN 网关切到 Tailscale 时，需要批准后停止并重新绑定。

下一步安装 Windows/安卓 **20261019.4**，先验证“检查更新”能从 20261019.1/20261019.3 发现并下载本版；再实测批准、双向访问、工作区名称、刷新、撤销授权及重启恢复。远程工作区开始编辑前须同步本次交付分支；除非 state.json 另有说明，上次已核验传输早于工作区版本。随后核查手机登录、切换设备、网络变化、前台恢复及长批注草稿，并验证打开应用直接回到上次电脑对话、断线状态条与自动重连、重连后停止按钮可用、多条批注的编号与评论归属，以及排队消息预览不再显示注解原文。窗口恢复（全部窗口 vs 仅主窗口）作为独立后续特性，需要跨进程设置 API、设置页开关与多显示器测试。不要把检测到 100.x 地址冒充设备发现。完整发布和官方升级另行处理。Electron 实测须使用独立配置，在测试配置中关闭发现，并恢复用户的协议关联。
