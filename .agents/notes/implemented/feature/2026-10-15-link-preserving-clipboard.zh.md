# Agent Note: 保留链接的纯内容复制

Status: implemented

[English](2026-10-15-link-preserving-clipboard.md) | 中文

## 问题

纯内容复制会丢弃链接地址，选中的文件名或文档链接无法方便地在对话外复用；恢复所有 Markdown 样式又不符合用户的无样式正文偏好。

## 决策

划词和整条消息复制保留 Markdown 链接、TeX 公式和 Markdown 表格。标题、强调、列表标记与代码围栏仍省略。链接文字仅包含所选可见内容，并转义字面括号和地址分隔符。整条消息源码投影按首个定义解析引用式链接；不支持的 URL 协议只保留文字。

剪贴板仅提供 text/plain。DSH 输入框的显式纯文本粘贴会去掉链接标记，并保持既有公式和表格展开规则。脱敏与注释引用行为不变。

## 考虑过的替代方案

富文本 HTML 剪贴板可能带回字体样式和重复公式字形；复制全部原始 Markdown 标记会恢复用户不需要的样式；只保留链接文字则丢失用户需要复用的地址。

## 影响

支持 Markdown 的目标软件可从粘贴文本还原链接；其他编辑器接收字面的 Markdown 链接文本。已有选区、整条消息、公式、表格、脱敏及纯文本粘贴测试覆盖不同路径。

创建注释的窗口支持 Ctrl+Enter 添加和 Esc 取消。普通回车仍用于换行，输入法选字和按键重复不会触发提交；暂时无法加入草稿时保留备注以便重试。
