# Agent Note: 持久讨论与明确管理的助手记忆

Status: implemented

[English](2026-10-15-persistent-discussions.md) | 中文

## 问题

用户需要在主对话旁讨论一段内容，并在关闭面板后保留讨论。每个话题都复制主对话全部历史会浪费存储并重复无关上下文。保存助手身份不应意味着模型持续运行，也不应自动将每个断言记成事实。

## 决策

每个话题记录主对话、原始引用和一个独立原生会话。现有会话存储负责消息与附件引用。关闭、标记解决和归档均保留历史。话题通过主对话链接使用现有的分页只读记录工具，不复制主对话历史。带回结论仅将用户确认的文字及链接插入主对话草稿，不发送消息，也不唤醒主 Agent。

保存的助手具有持久名称和职责，不带后台执行循环。临时、项目和常驻模板分别选择关闭、仅项目、助手加当前项目的记忆范围；用户可独立修改记忆设置。只有明确保存才创建记忆条目。现有留痕的系统上下文链路包含有大小上限的确认记忆，并关闭变量插值以原样保留引用。话题初始权限为只读，仍可使用普通的明确权限控制。

## 考虑过的替代方案

社区临时侧边任务在使用后删除，不符合保留讨论的需求。自动分叉全部主对话历史会增加存储和无关上下文。自动从每条消息提取长期事实，会让错误及暂定想法未经审阅就成为记忆。常驻多智能体聊天室还会引入超出单个侧边讨论范围的调度、循环和预算行为。

## 后果

首版提供手动刷新，每个话题选择一个助手。搜索、未读数量、自动提取记忆和多成员调度属于后续独立工作。确认记忆可以编辑、关闭或删除，不影响对话记录。项目匹配使用精确 Host 工作区标识。版本检查保护并发的助手配置和记忆编辑；话题创建使用幂等键。创建和浏览话题无需模型执行。
