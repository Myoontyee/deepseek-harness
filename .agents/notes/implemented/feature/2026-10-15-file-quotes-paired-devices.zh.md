# Agent Note: 文件引用与已配对设备对话

Status: implemented

[English](2026-10-15-file-quotes-paired-devices.md) | 中文

## 问题

文件预览选区缺少输入框操作，多设备连接需要手动地址且会话浏览分散。

## 决策

文件预览选区通过现有会话 inputActions 注释入口添加。引用保留渲染内容的 Markdown、公式和文件地址，备注为独立草稿字段；不新增提交格式，也不导入其他插件的组件实现。隔离 HTML iframe 内的选区暂不支持。

桌面设备发现由用户开启，读取已安装 Tailscale 客户端的本机状态，不授予访问权限。电脑生成的一次性邀请固定远端证书，并要求在该电脑确认。凭据通过本机系统加密服务保存，原生 IPC 仅返回公开设备信息和会话摘要。远端会话在不含本机 preload 的隔离窗口打开，标题始终带有设备名称。仅在设备面板挂载时轮询。

安卓扫码仅填入配对码，不自动授权或连接。二维码在本机生成，相机权限属于原生扫描器，不属于远端 WebView。

## 验证

选区测试覆盖 Markdown 公式、来源、备注添加失败保留和可编辑区域排除。真实 HTTPS 监听器验证在传输密钥前拒绝错误证书、显式配对、授权会话 RPC 和撤销后的访问拒绝。X.509 序列化器与扩展类型使用相同的 schema 版本，测试覆盖首次生成身份，而不只验证已存在身份的恢复。

## 考虑过的替代方案

复制远端会话到本地会重复历史并混淆任务执行归属；自动信任发现的设备会绕过明确授权。

## 影响

电脑和 DSH 必须保持运行。Tailscale 可见不代表 DSH 或 SSH 可用。此功能不提供公网中继、远程开机或 iOS 应用。远端摘要按设备分组，不复制进本机会话存储。
