# 安卓手机聊天与可选电脑连接

[English](guide.md) | 中文

## 变更

安卓通过官方 DeepSeek 浏览器授权后直接进入手机聊天，使用与桌面版相同的账号认证模型接口，无需连接电脑。对话、草稿和批注按账号保存在本机压缩 SQLite 存储中。原有加密电脑授权仍保留。设置中提供内置 Tailscale 发现与电脑连接；新电脑仍需本地批准，二维码作为局域网备用入口。已授权手机可以向桌面版同步仅含对话与批注的副本，不同步 DeepSeek 云端聊天历史。远程对话在手机记录列表中用地球图标区分；远程操作页面不再额外显示原生配对工具栏。

## 迁移

1. 在原安装上覆盖安装新 APK，不要清除应用数据。同时更新桌面版，以支持手机记录同步和修正后的授权超时处理。
2. 通过官方浏览器页面登录一次，再返回应用。如果官方服务提示网络错误或限流，保留应用数据并稍后重试。
3. 确认手机无需配对便能进入消息输入框。选择账号可用的模型和思考强度；长按回答可添加批注，引用与评论分别保存，发送时一并作为用户消息记录。
4. 如需连接电脑，打开“设置 → 设备与对话”，登录应用内 Tailscale，再选择可连接的 DSH 电脑。在电脑确认一次。手机安装的 Tailscale VPN 不会向本应用暴露其私有登录凭据。
5. 打开手机对话记录，点击带地球图标的远程对话。电脑的“设备与对话 → 手机对话”可预览已同步的手机副本。安卓设置中可关闭手机记录同步，桌面版“手机控制”可撤销设备授权，停止后续访问。
