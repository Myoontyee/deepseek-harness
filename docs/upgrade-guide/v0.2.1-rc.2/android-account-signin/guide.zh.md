# 安卓访问电脑前先登录账号

[English](guide.md) | 中文

## 变更

安卓端先打开官方 DeepSeek 浏览器授权流程，再显示电脑访问入口。已有的加密电脑授权仍会保留。账号登录不会授予电脑控制权限，也不会通过 DeepSeek 云端同步对话。连接管理移至设置，手机注释使用已连接电脑的对话和文件编辑器。

## 迁移

1. 在原安装上覆盖安装新 APK，不要清除应用数据。
2. 通过官方浏览器页面登录一次，再返回应用。如果官方服务提示网络错误或限流，保留应用数据并稍后重试。
3. 打开“设置 → 连接”检测 VPN 私网地址、打开 Tailscale 或重连已保存电脑。新电脑仍需要一次性二维码邀请和本地确认。
4. 确认可以打开已保存电脑，然后长按文字并选择“添加注释”。发送前核对输入框中选文引用与备注分别显示。
