# 常驻助手和侧边讨论区退役

[English](guide.md) | 中文

## 变更

定制桌面版不再提供常驻助手设置、助手 @ 候选、讨论面板和划词讨论操作。讨论 API 保留历史读取操作，移除创建和修改方法。保存的助手配置、明确记忆及原生对话日志保留，旧回复中的身份标记仍可阅读。

## 迁移

1. 在已有安装上安装新版定制桌面客户端，不删除 Harness 数据目录。
2. 通过普通对话列表继续旧讨论会话。之前选中过助手的对话首次继续时会恢复记录的普通模型并结束旧角色；之后明确选择的模型优先。
3. 停止调用已移除的助手和话题修改 API，改用普通对话的模型选择和消息功能。
4. 确认设置不再显示常驻助手、讨论操作已消失，并且历史对话仍可阅读。
