# 安卓版 DeepSeek Harness Desktop

[English](README.md) | 中文

定制安卓版提供账号认证的手机聊天和可选电脑连接，并非 DeepSeek 官方安卓版本。需要 Android 8.0 及以上和较新的 Android System WebView。应用名称及鲸鱼图标与桌面版一致。

## 聊天与批注

通过 DeepSeek 官方浏览器授权登录。手机聊天使用与桌面版相同的账号授权、模型列表和 Messages 接口，不需要配对电脑或填写 API Key。发送前选择账号模型和思考强度；仅主动发送消息才调用模型。此处为纯文字聊天，不执行桌面工具，也不同步 DeepSeek 云端聊天历史。

手机对话、部分回答、草稿及批注按账号保存在 SQLite 中，对话正文使用 gzip 压缩。长按已渲染文字可添加引用及独立评论，选文保留 Markdown 链接、表格和原始 TeX 公式。已识别凭据在显示、复制和添加批注前脱敏。批注草稿自动保存；Esc 关闭编辑器但保留草稿，Ctrl+Enter 保存批注。发送时，待发送批注会加入可见且持久保存的用户消息。

## 可选电脑连接

1. 打开“设置 → 设备与对话”。应用内 Tailscale 使用独立私有节点和官方浏览器登录；手机安装的 Tailscale VPN 无法共享其私有凭据。设备发现在此处进行，不再是手机聊天的前提。
2. 仅检测在线设备是否提供 DSH 服务。选择可连接电脑，在电脑确认一次。电脑和 DSH 须保持运行。已授权连接无需再次扫码或填写地址，二维码仍可用于局域网备用连接。
3. 手机对话记录中以地球图标标识远程对话，点开直接进入电脑操作页，不再显示额外的原生配对工具栏。安卓返回键先返回页面历史，再回手机聊天。远程文字可长按选择“添加注释”，使用电脑已有编辑器。
4. 应用在前台时，手机对话与批注同步到已授权电脑。电脑“设备与对话 → 手机对话”可只读预览；手机回答在手机继续发送，电脑任务在电脑执行。安卓设置可关闭同步；电脑离线时保留改动，之后回到应用前台再同步。
5. 桌面版“手机控制”中撤销设备会中止访问并隐藏其手机副本。手机清除凭据不会撤销离线电脑上的授权。每台电脑最多授权八台设备。

## 身份验证与保存

官方账号及电脑授权分别使用 Android Keystore AES-GCM 保存。本地聊天 WebView 只对安装包内应用资源来源的主页面开放受限消息桥；远程电脑页面没有原生桥接。连接必须匹配已批准的证书指纹并通过有效期检查，跳转不携带凭据。外部链接在浏览器打开，不携带设备 Cookie。桌面版 Host 内部凭据仅保留在电脑，手机副本压缩后使用系统加密保存。手机数据位于应用私有空间，备份已禁用。

## 构建与验证

使用 JDK 17、SDK 35、Build Tools 35.0.0、Gradle 8.11.1、Go 1.27.1、NDK 28.2.13676358 和仓库 Node/pnpm 依赖。直接运行 Gradle 前先执行 `node apps/android/ui/build.mjs`。生成资源和原生库由 Git 忽略，APK 内附第三方许可声明。

Windows 本机使用 `pwsh -File apps/android/scripts/build-local.ps1 -ToolsRoot <缓存目录> -OutputRoot <安装包目录> -KeyStore <私有签名库> -PasswordFile <私有密码文件>`。脚本最多使用八个逻辑处理器、两个工作任务，复用缓存，编译 ARM64 及界面，本地签名并核对旧安装证书。`-Version` 与 `-VersionCode` 指定升级版本；`-Unsigned` 跳过签名。`-ProxyUrl` 可覆盖笔记本默认的 17897 代理，空值表示直连。私钥及密码禁止进入源码、GitHub Secrets、Release 或传到 4090。

`:app:testReleaseUnitTest` 核查账号模型协议；`tailnet/` 中的 `go test ./...` 核查固定证书传输；界面构建后运行 `node apps/android/tests/chat-ui-smoke.mjs` 检查浏览器行为。安卓仪器测试覆盖应用权限下的 Tailscale 启动、可选连接入口和本地数据库持久化。这些检查不代替真机账号登录及完整跨设备验收。目前没有后台推送、语音采集、网络唤醒、公网中继或屏幕鼠标远程桌面服务。相机权限仅用于原生扫码器，网页摄像头和麦克风请求被拒绝。
